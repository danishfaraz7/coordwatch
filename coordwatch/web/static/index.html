Connections, privacy and storage

  
Connections

  

  
Import-only platforms

  
TikTok, Instagram, Facebook and Snapchat have no public search API. Use their chips in the toolbar to import an export file (JSON/CSV), e.g. from an Apify actor or your own lawful collection.

  
Run logs

  
Export the secret-free logs (topic, dates, platforms, route used, errors) of runs started in a date range, so you can share them.

  

    

  
Privacy & storage

  
    
    
  • Keys are write-only: saved on this computer, never sent back to the browser, and never committed to the repository.
    • 
    
  • 
    
  • Environment variables (e.g. Codespaces secrets) take priority over saved values.
    • 
    
  • AI answers are off by default. When enabled, only a summary of a run is sent to Gemini.
