API keys & storage

  
Keys are write-only: they are saved on this machine and never sent back to the browser. Environment variables
  (e.g. Codespaces secrets) take priority over saved values.

  

  

  

  
How do I get each key?
    
    
  • YouTube: Google Cloud Console → new project → enable YouTube Data API v3 → Credentials → API key (free quota).
    • 
    
  • Telegram: my.telegram.org → API development tools → api_id / api_hash. Then run python -m coordwatch telegram-login once in a terminal.
    • 
    
  • Gemini (optional AI chat): aistudio.google.com/apikey → Create API key (free tier). Off by default; opt-in per session with the AI checkbox.
    • 
    
  • X: developer.x.com → Basic tier or higher (paid) → Bearer token.
    • 
    
  • TikTok / Instagram / Facebook / Snapchat: no public search API — import an export file (JSON/CSV) with the chip.
